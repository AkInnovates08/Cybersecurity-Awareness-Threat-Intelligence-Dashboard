# Industry Concepts Used

## Cybersecurity Awareness
Simple: teaching people how to recognize and avoid common security risks.
Technical: user-focused controls that reduce the probability and impact of social engineering, credential theft, unsafe browsing, poor authentication and data mishandling.

## Cyber Threat Intelligence
Simple: information about threats that helps defenders make decisions.
Technical: structured, contextualized intelligence about indicators, adversary behaviors, campaigns, vulnerabilities and defensive implications.

## IOC
Indicator of Compromise. Examples: IP, domain, URL, hash, sender domain. An IOC can be stale or benign in context.

## IOA
Indicator of Attack. A behavioral pattern that may signal adversary activity. This project uses only high-level defensive examples.

## Vulnerability / CVE / CVSS
A vulnerability is a weakness that can be abused. CVE is a standardized identifier. CVSS is a severity scoring framework. CVSS alone should not dictate patch order.

## Threat Feed / Enrichment / Correlation
A feed supplies observations. Enrichment adds local context. Correlation groups related evidence. None of these automatically proves compromise or attribution.

## SOC
A Security Operations Center monitors, triages, investigates and coordinates response to security events.

## Roles Demonstrated
SOC Analyst: triage and investigate alerts. CTI Analyst: interpret threat intelligence. Incident Response Analyst: use investigation context. Security Engineer: build controls. Vulnerability Analyst: prioritize weaknesses. Awareness Specialist: teach safe behavior. Threat Hunter: investigate patterns proactively.

## Intelligence Types
Strategic: long-term decisions. Tactical: TTP-oriented defensive knowledge. Operational: campaign/activity context. Technical: concrete indicators and telemetry.
